田中さんの ChatGPT のプロジェクトの分け方（2026-10-21 の画面）に合わせた案。台帳（`projects.yaml`）は 1 段の並びなので、グループを slug の頭（prefix）で表す。

## グループと prefix

| prefix | グループ（ChatGPT のフォルダ） |
|---|---|
| `shacho-` | 社長案件｜他法人・社外活動 |
| `kuchikomi-` | 口コミ広場｜事業・プロダクト |
| `keiei-` | 経営推進｜社長・三上・全社戦略 |
| `admin-` | ADMIN｜管理部・専門家相談 |
| `web-` | WEBConsulting |

- ChatGPT の「INBOX」は、この repo の `_inbox/`（どこに入れるか決まっていないものの置き場）に当たる。プロジェクトにはしない
- ChatGPT の「案件マスター」は、各プロジェクトの `README.md`（状態・関係する人・次の一手）に当たる
- 会社で共通の分け方の目安（dev-tools の `project-catalog`）では、口コミ広場は `biyou-`・`salon-`、管理は `roumu`・`seikyu` などの頭を使う。ここでは田中さんの分け方を優先した
